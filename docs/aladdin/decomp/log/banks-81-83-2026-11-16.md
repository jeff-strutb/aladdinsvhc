# Banks $81 and $83: what was filed, and what blocks the rest (2026-11-16)

Filed this round, C and symbolic assembly with the same headers, each batch
byte exact in the image: the backdrop's parallax and band HDMA table
(video/parallax), the camera's nine scroll handlers (video/scroll_update),
the frame's actor sprites (video/oam), the levels' screen set-ups
(level/level_screen_setups), the per-level backdrop start
(level/level_backdrop), the copier check task (game/mirror_check_task),
PauseCheck released with its exit flags fixed, the player's whole state
machine, starts and carpet ride (player/), and most of bank $83's kinds,
waits and stubs (actor/).

## What blocks the rest

- **The actor loops** ($83:9475 player, $83:94A4 the others, $83:94D3).
  check.c opens an actor's piece only where the original core executes
  the loop's `JMP (table,X)`, resumes one only on the original's `RTI`,
  and ends a piece where original code reaches $83:948B or $83:94BF. C
  for the loops needs a resume primitive (cdraft leaves a TODO at the
  RTI, $83:9501), actor C started as an actor piece rather than nested in
  the loop's call, and re-entry at $948B/$94BF. A design decision for the
  oracles; until then the frame step ($81:8311 and up, ~4 KB) waits.
- **UnpackSet** ($81:BAF1): its C was identical per call, but the A7
  lockstep loses its place after an interrupt inside the long unpack
  (rand_stage_a8_s0 frame 251) and never finishes. About 5 KB waits
  (levels 7 and $11's screen set-ups, the dispatcher at $81:87EF, the
  level start).
- **Calls that leave past their exit level** (KindA1Touch, $81:DD1E's
  hurt path): A5 has no rule that ends them, so they read DIVERGENT with
  exact C.
- **Code a retail cartridge cannot run**: copier checks (kind $20's
  $70:0023 test, MirrorCheckTask's ROM mirror and $70:0080 tests),
  branches a compare rules out (BandTable's zero-line band), table words
  no level selects (ScrollUpdate's kind 16). Gate C needs every byte run;
  EXCLUDED covers only whole routines.
- **The task scheduler** ($81:BC6D, $81:BC7F) switches stacks by TCS and
  $81:B9F1 pulls its caller's frame: task primitives, outside cdraft.

## Rules found

- A tail jump into an actor entry is `actor_leave` from code that is not
  itself an actor entry (the catalog's `actor`, or `@actor`), and a tail
  call from code that is (cdraft's tail()). Kind $20's Spotted and Halt,
  catalogued as jumps, hand on to Charge and LookAbout by actor_leave.
- t3.py reruns every script when any commit since a script's last pass
  touches src/aladdin/include/ or any non-.c file in the C tree (.held
  files too). New C names go in the .c that uses them; .held releases are
  batched into one commit per gate.
- On a lockstep timeout t3 killed only the snesbox it started; the side it
  forks ran on as an orphan in the gate's CPU scope and starved the gate.
  Each snesbox now leads a process group that is killed whole (3155347).
- asar defines are global across every filed file: a new `!name` that
  another file defines with another value assembles wrong bytes silently
  (BandTable's `!band_count`, placement.asm's $7EC100).
